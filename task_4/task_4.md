Практическое задание 4
Постановка задачи
Требуется реализовать алгоритм Быстрой Сортировки (Quick Sort) без использования рекурсии.

Требования к реализации
1. Нельзя использовать библиотечные реализации быстрой сортировки.

2. Крайне желательно добавить комментарии, поясняющие, что происходит на каждом шаге алгоритма.

Класс, в котором нужно реализовать алгоритм, находится в QuickSort.java.

Тесты, которые проверяют корректность реализации, находятся в QuickSortTest.java.

Критерий приёма
Для работы требуется Java 21.

Запуск тестов выполняется через ./gradlew test. Задание считается выполненным, если все тесты успешно пройдены.

Если проект написан не на Java (Kotlin) + Gradle, то нужно переписать unit-тесты на другой язык, и приложить инструкцию, как настроить окружение и запустить тесты.

Приём задания
Для сдачи задания требуется приложить архив проекта. В процессе приёма будут запускаться тесты ./gradlew test. Их успешное прохождение является необходимым условием принятия работы.
