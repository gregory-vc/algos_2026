Практическое здание 7
Условие
В рамках материала по динамическому программированию необходимо практически реализовать алгоритм поиска наибольшей общей подпоследовательности двух строк, который был разобран в теории на вебинаре. Для решения может быть использован любой язык программирования, в котором есть возможность представлять строку как объект с возможностью доступа к отдельным буквам, либо же можно использовать вместо строки чистый массив букв. Решение принимается только в том случае, если оно выполнено методом динамического программирования.

Задание
Реализуйте функцию, принимающую на вход две строки, и возвращающую массив строк. Результирующий массив перечисляет все подпоследовательности максимально возможного размера, которые могут быть построены на основе исходных строк.

Пример:

Входные данные:

Строка 1: ABDEFADRFG

Строка 2: DAFERG

Выходные данные:

[DAFG, AFRG, AERG, DFRG, DERG, DARG]

ПО для выполнения задания и как развернуть окружение
Выполнять задание можно в любой IDE.

Формат результата
Решение должно быть представлено в форме исходного кода, включающего реализованный метод и тесты демонстрации его работоспособности.

Код может быть прислан через платформу любым удобным способом:

ссылка на пул-реквест. В этом случае необходимо сделать репозиторий публичным или прислать инвайт на проверяющего;
файлы\архив с решением.
Критерии проверки
Решение оценивается по принципу «зачёт\незачёт». Для зачёта код должен проходить предложенный в примере тест, аналогичные скрытые тесты и быть реализован методом динамического программирования.

Эталонное решение
К заданию приложен архив с JAR-файлом algos-7.0-sources.

В файле присутствует пример реализации всего необходимого кода, а также main метод, который при запуске показывает README с рекомендациями по реализации. При необходимости получить подсказки к решению сначала рекомендуется попробовать прочитать только README, и в случае, если он не поможет, — перейти к чтению готового решения.

JAR-файлы в общем смысле являются архивами, поэтому могут быть открыты любыми архиваторами.
