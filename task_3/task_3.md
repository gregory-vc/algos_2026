Практическое задание 3
Условие
На вебинаре разбиралась реализация некоторых базовых структур данных, в том числе связного списка. Связный список, в теории, обладает тем достоинством, что вставка в любую позицию выполняется за O(1). Однако в рамках конкретной реализации может оказаться так, что для вставки в позицию необходимо искать эту позицию и вставка превращается в O(n).

В рамках задания необходимо реализовать на выбранном языке программирования связный список, имеющий важное условие: вставка в произвольное место данного списка может быть выполнена за гарантированное O(1).

Задание
Необходимо разработать коллекцию для хранения значений произвольного типа, которая имеет следующие методы:

вставка в начало\конец\указанную позицию (за O(1));
поиск наличия значения (не хуже, чем за O(N));
определение позиции искомого элемента (не хуже, чем за O(N));
удаление значения из начала\конца\указанной позиции (за O(1));
получение значения из указанной позиции (за O(1));
замена значения в указанной позиции (за O(1)).


ПО для выполнения задания и как развернуть окружение
Выполнять задание можно в любой IDE.

Формат результата
Решение должно быть представлено в форме исходного кода, включающего класс реализованной коллекции, и тестов демонстрации работоспособности кода.

Код может быть прислан через платформу любым удобным способом:

ссылка на пул-реквест. В этом случае необходимо сделать репозиторий публичным или прислать инвайт на проверяющего;
файлы\архив с решением.
Критерии проверки
Решение оценивается по принципу «зачёт\незачёт», если решение содержит все необходимые методы и сложность их выполнения соответствует требуемой.

Эталонное решение
К заданию приложен архив с JAR-файлом algos-3.0-sources.

В файле присутствует пример реализации всего необходимого кода, а также main метод, который при запуске показывает README с рекомендациями по реализации. При необходимости получить подсказки к решению сначала рекомендуется попробовать прочитать только README, и в случае, если он не поможет, — перейти к чтению готового решения.

JAR-файлы в общем смысле являются архивами, поэтому могут быть открыты любыми архиваторами.
