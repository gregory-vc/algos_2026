## Практическое задание 10

## Условие

В рамках второго вебинара, посвященного парадигмам программирования, разбирались вопросы реализации функционального подхода к программированию. Задание представляет собой требование написать решение по обработке списка значений в функциональном стиле. В языке Java это делается через StreamAPI. При применении других языков следует внимательно отнестись к критериям соответствия кода функциональной парадигме. Явное выделение циклов и условий, как правило, является признаком процедурного подхода и не будет принято.

## Задание

Дан текстовый файл со строками, где каждая строка содержит имя человека и его номер. Среди этих строк:

- возможны повторения;
- возможны два разных имени под одним номером;
- возможно наличие людей без номера.

Необходимо обработать данные этого файла в функциональном стиле таким образом, чтобы соблюдались следующие условия:

- люди без номера не попадают в итоги;
- все имена должны быть записаны в нижнем регистре с первой буквой в верхнем регистре;
- результатом будут списки людей, сгруппированные по их номеру.

Если это применимо, то выполните автоматическую параллелизацию получения результата.

**Пример:**

Входные данные:\
вася 5\
Петя 3\
АНЯ 5\
Тото

Выходные данные:\
[5:[Вася, Аня], 3:[Петя]]

## ПО для выполнения задания и как развернуть окружение

Выполнять задание можно в любой IDE.

## Формат результата

Решение должно быть представлено в форме исходного кода, включающего реализованный код метода и тесты демонстрации его работоспособности.

Код может быть прислан через платформу любым удобным способом:

- ссылка на пул-реквест. В этом случае необходимо сделать репозиторий публичным или прислать инвайт на проверяющего;
- файлы\архив с решением.

## Критерии проверки

Решение оценивается по принципу «зачёт\незачёт», с учётом наличия признаков функционального программирования и достижения результата этим кодом.

## Эталонное решение

К заданию приложен архив с JAR-файлом algos-10.0-sources.

В файле присутствует пример реализации всего необходимого кода, а также main метод, который при запуске показывает README с рекомендациями по реализации. При необходимости получить подсказки к решению сначала рекомендуется попробовать прочитать только README, и в случае, если он не поможет, — перейти к чтению готового решения.

JAR-файлы в общем смысле являются архивами, поэтому могут быть открыты любыми архиваторами.
