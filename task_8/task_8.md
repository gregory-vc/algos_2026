Практическое задание 8
Постановка задачи
Требуется написать код парсера, который на вход будет получать строку, а на выходе отдавать строку со скрытыми чувствительными данными в нём. При реализации желательно использовать паттерны проектирования.

Чувствительных полей может быть более одного в строке, они могут идти в произвольном порядке.

Правила маскирования:

1. Логин: если логин меньше или равен 7 символам, то все символы кроме первого заменяются на *. Иначе (если больше 7 символов) берётся первый, второй и последний символ, остальное заменяется на ***. Поля имеют префикс: login=. Например: login=romanow -> login=r******; login=testadmin -> login=te***n.

2. Ф. И. О: маскируется фамилия и отчество по правилу выше (логин). Имя (оно идёт всегда вторым) не маскируется. Поля имеют префикс: name=. Например: name=Романов Алексей Сергеевич –> name=Р****** Алексей Се***ч, name=Гогия Владимир -> name=Г**** Владимир.

3. Электронная почта: заменить имя пользователя (все символы до @) на первый символ + ***. Поля имеют префикс: email=. Например: email=admin@example.com -> email=a***@example.com.

4. Номер Карты: отображаются первые шесть и последние четыре цифры номера. Поля имеют префикс: card=. Например: card=4111 1111 1111 1234 -> card=4111 11** **** 1234.

Требования к реализации
1. Нельзя использовать библиотечные реализации маскирования.

2. В реализации для поиска чувствительных полей нужно использовать регулярные выражения.

3. Крайне желательно добавить комментарии, поясняющие, что происходит на каждом шаге алгоритма.

Класс, в котором нужно реализовать алгоритм, находится в MaskingParser.java.

Тесты, которые проверяют корректность реализации, находятся в MaskingParserTest.java. Пример входного файла test/resources/input.log, ожидаемый результат test/resources/result.log

Критерий приёма
Для работы требуется Java 21.

Запуск тестов выполняется через ./gradlew test. Задание считается выполненным, если все тесты успешно пройдены.

Если проект написан не на Java (Kotlin) + Gradle, то нужно переписать unit-тесты на другой язык, и приложить инструкцию, как настроить окружение и запустить тесты.

Приём задания
Для сдачи задания требуется приложить архив проекта. В процессе приёма будут запускаться тесты ./gradlew test. Их успешное прохождение является необходимым условием принятия работы.
